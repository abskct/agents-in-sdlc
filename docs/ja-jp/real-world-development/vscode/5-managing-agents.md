GitHub Copilot をエージェント モードで使うと、コードベースを調べ、変更を提案してファイルを編集し、コマンドを実行するなど、自律的に作業します。Copilot Chat in VS Code は、ローカル環境でリアルタイムに実行されるすべてのツール呼び出しやファイル編集を表示します。エディター内で各差分を確認して個別の変更を承認または元に戻し、追加のプロンプトを送って会話の方向を調整できます。

この演習では、次のことを行います。

- アクセシビリティ エージェントの作業をリアルタイムで監視します。
- 提案されたファイル編集をレビューし、承認します。
- セッションの途中でエージェントに指示し、ハイ コントラストに加えてライト モードの切り替えを追加します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティのカスタム エージェントが、ハイ コントラスト モードを実装しています。作業中、デザイン チームから追加の要望がありました。既定のテーマが暗すぎると感じる利用者向けに、ライト モードの切り替えも追加します。新しい会話を始める代わりに、現在のセッションに追加の指示を与え、作業を拡張します。

## Copilot の進捗状況を監視する

Copilot Chat ビューには、エージェントが実行する各手順が表示されます。調べたファイル、実行したコマンド、提案した編集などを確認できます。ファイルの編集は差分と **Keep** / **Undo** のコントロールとともに、チャット内に表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントが作業している間、チャットをスクロールしてツール呼び出しを確認します。ファイルの読み取りや編集、実行を求めるターミナル コマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分がチャット内に表示されます。
    - **Keep** を選択すると変更を承認します。
    - **Undo** を選択すると変更を元に戻し、エージェントにもう一度作業させます。
4. チャット上部の **Files changed** の表示を開くと、セッション中にエージェントが変更した作業ファイル全体を確認できます。

> [!NOTE]
> ターミナル コマンドの実行など、ツール呼び出しの許可を求められると、エージェントは一時停止して **Allow** を表示します。内容を確認し、実行してもよいコマンドのみ承認してください。

5. エージェントがハイ コントラスト モードを実装し終えるまで待ちます。最後に、行った変更をまとめるメッセージが表示されます。

## ライト モードを追加するようエージェントに指示する

ハイ コントラスト モードができたら、同じ会話でライト モードの切り替えを追加します。同じチャット セッションを続けるため、エージェントは前の作業で得たコンテキストを引き継ぎます。変更したコンポーネント、採用したスタイル、設定した local storage のパターンなどが含まれます。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントは前の作業を引き継ぎ、すでに行った変更を確認しながらライト モードの追加を提案します。
3. ハイ コントラスト モードの場合と同様に、新しい編集を確認します。各差分に対して **Keep** または **Undo** を選択します。
4. エージェントが意図しない方向に進んだ場合、たとえば気に入らない方法でトグル UI をリファクタリングしようとした場合は、チャット入力欄の横にある **Stop** ボタンで停止し、明確な指示を追加で送信します。

> [!TIP]
> 進行中のセッションに指示を与えるほうが、最初からやり直すより短時間で済みます。追加プロンプトを使って調整を依頼します (「CSS を簡潔にして、セレクターの重複ではなく CSS 変数を使う」)、方向を修正します (「トグルを 3 つに増やさず、既存の設定パネルにライト モードを追加する」)、または範囲を広げます (「2 つのトグルにキーボード ショートカットも追加する」)。

## 作業ファイルをレビューする

作業をコミットする前に、エージェントが変更したすべてのファイルを簡単に確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが更新されているはずです。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタム エージェントが指示したアクセシビリティのパターン、ARIA 属性、キーボード操作、セマンティック HTML、local storage による設定の保持などが反映されていることを確認します。
4. 内容に問題がなければ、Source Control パネルから変更をステージングしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェント モードを使って進行中のセッションを監視し、方向を調整しました。ファイル編集を確認して承認または元に戻し、コンテキストを失わずに追加プロンプトを送信して作業を拡張しました。

このレッスンでは、次のことを確認しました。

- エージェントの作業をリアルタイムで監視する方法。
- 個々のファイル編集を承認または元に戻す方法。
- 追加プロンプトを使って、進行中のセッションの方向を調整する方法。
