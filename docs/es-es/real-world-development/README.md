Explora GitHub Copilot durante todo el ciclo de vida de desarrollo de software con escenarios realistas, una aplicación completa y una lista de tareas compartida. Trabajarás de forma iterativa para planificar cambios, escribir código, probar el comportamiento, revisar solicitudes de incorporación de cambios y administrar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa y tiene una temática de desarrollo. Las tareas del equipo ya están registradas como incidencias de GitHub. Incluyen características como el filtrado y la paginación, además de mejoras de calidad, como la accesibilidad y los estándares de programación.

## Elige el entorno

GitHub Copilot está disponible en los entornos donde trabajas. Elige el que mejor se adapte a la forma en que quieres desarrollar. Cada taller incluye su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes desde el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, aptitudes, agentes personalizados, MCP de Playwright, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia de modo, colabora con lienzos y administra incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo Agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
